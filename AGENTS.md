# Project instructions

## AI interaction log

- Record every Codex interaction used for this project in `llm_log/`.
- Create a new uniquely named file for each interaction. Never overwrite an existing log.
- Record the local date and time with timezone, team member, Codex model, and line ranges for changed text files. List binary artifacts by path.
- Preserve the complete user prompt and assistant response verbatim, including prompt attachments when available. List all files created or modified and record the verification outcome.
- Include prior project interactions when their complete transcripts are available. Never invent or reconstruct missing transcripts.
